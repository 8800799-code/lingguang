# 灵光

灵感闪一下的时候先记下来。原稿只留在这台设备上。只有按下整理、描写、提升、雕琢或汇总时，才会把那一则发给写作助手。

## 能变成什么

诗、一段话、图片、风景、创意、灵感、应用。

也可以直接落到结果：

- **落实**：一个突然的项目，写成今天能交付的结果、第一步、会卡在哪里
- **升级**：看见一个产品，改成更好的一版
- **路径**：从一条新闻里理出能走的路。不承诺赚到，也不写不干净的做法
- **我做**：看见别人在做，换成自己的版本

## 本地运行

需要 Node.js。写作和画图读取环境变量 `XAI_API_KEY`，不要写进仓库。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:8080
